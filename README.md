## ◆ Deskripsi Projek

**Kopi dan Nyemil** adalah aplikasi mobile berbasis Android yang dirancang untuk memenuhi penugasan Ujian Tengah Semester (UTS) Mata Kuliah Pemrograman Mobile. Mengusung konsep modern *Neo-Brutalist* dengan sentuhan palet warna pastel yang *playful*, aplikasi ini menghadirkan pengalaman navigasi antarmuka yang bersih, interaktif, dan ramah pengguna.

<br>

## ◆ Konsep Desain & Estetika

> **Gaya Visual**
> Neo-Brutalisme / Web Brutalism dengan elemen *border* hitam tebal yang tegas, sudut *rounded* minimalis, serta kombinasi warna pastel kontras yang estetik.

## ◆ Alur & Fitur Aplikasi

Aplikasi ini sepenuhnya mengimplementasikan alur navigasi lengkap sesuai dengan *wireframe* standar penugasan, yang mencakup **8 halaman utama**:

| No | Halaman | Deskripsi Fungsionalitas |
| :---: | :--- | :--- |
| **01** | **Splash Screen** | Halaman pembuka dengan logo ikonik cangkir kopi dan tombol *"Start now"*. |
| **02** | **Sign Up** | Gerbang awal autentikasi dengan pilihan menu *Register* atau *Login*. |
| **03** | **Login** | Form masuk pengguna berbasis *card-based layout* yang minimalis. |
| **04** | **Register** | Pendaftaran akun baru dengan input nama lengkap, username, dan password. |
| **05** | **Home Screen** | Menampilkan sapaan dinamis (*"Halo [Nama]"*) serta katalog **5 menu unggulan**:<br>☕ Kopi Susu Gula Aren — Rp 22.000<br>🍩 Donat Cokelat — Rp 12.000<br>🍞 Sourdough Loaf — Rp 35.000<br>☕ Cappuccino — Rp 25.000<br>🍵 Matcha Latte — Rp 27.000 |
| **06** | **Profile** | Pengaturan informasi profil pengguna dengan fitur simpan (*Save*). |
| **07** | **Alamat Pengiriman** | Form interaktif untuk memasukkan alamat tujuan serta detail patokan kurir. |
| **08** | **Konfirmasi Pesanan** | Layar sukses bertuliskan pesan konfirmasi dengan ikon centang hijau pastel. |

## ◆ Panduan Instalasi & Penggunaan

**1. Clone Repository**

```bash
git clone https://github.com/Ghevyra/KopiDanNyemil.git
```

**2. Buka Projek**

Buka folder hasil clone melalui Android Studio, lalu tunggu proses *Gradle sync* selesai.

**3. Jalankan Aplikasi**

Pilih emulator atau perangkat Android, kemudian tekan tombol **Run**.
